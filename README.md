# RHPS Systems

Site institucional da RHPS Systems: criação de sites, aplicativos e sistemas sob medida.

Site estático (HTML e CSS puros), publicado pelo GitHub Pages.

## Ajustes rápidos

- **WhatsApp:** o número (com 55 e DDD) está nos links `wa.me` de `index.html`.
- **Domínio:** quando o domínio estiver registrado, ajuste `rhpssystems.com.br` em `index.html`, `robots.txt` e `sitemap.xml`, e atualize o arquivo `CNAME`.

## Ver localmente

```
python3 -m http.server 8000
```

Depois abra http://localhost:8000.
